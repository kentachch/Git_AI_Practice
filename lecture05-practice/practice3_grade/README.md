# 問題3：成績は A？ B？

点数を入れて［実行］を押すと、**80点以上**なら成績「A」、それ以外は「B」と表示します。

- 書きかえるファイル：`practice3_grade/script.js` の `grade` 関数だけ
- ブランチ：`practice3`
- AI への頼み方のひな形：`prompts/practice3.md`

## 確かめ方

`index.html` をブラウザで開き、次の値を入れて［実行］を押します。

| 入れる値 | 表示されれば OK |
|---|---|
| 90 | A |
| 80 | A（ちょうどの値） |
| 70 | B |

3つとも OK なら、add・commit・push に進みます。
