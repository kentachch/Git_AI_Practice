# 問題2：成人？ 未成年？

年齢を入れて［実行］を押すと、**18歳以上**なら「成人です」、それ以外は「未成年です」と表示します。

- 書きかえるファイル：`practice2_age/script.js` の `checkAge` 関数だけ
- ブランチ：`practice2`
- AI への頼み方のひな形：`prompts/practice2.md`

## 確かめ方

`index.html` をブラウザで開き、次の値を入れて［実行］を押します。

| 入れる値 | 表示されれば OK |
|---|---|
| 20 | 成人です |
| 18 | 成人です（ちょうどの値） |
| 15 | 未成年です |

3つとも OK なら、add・commit・push に進みます。
