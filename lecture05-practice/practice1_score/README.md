# 問題1：合格？ 不合格？

点数を入れて［実行］を押すと、**60点以上**なら「合格」、それ以外は「不合格」と表示します。

- 書きかえるファイル：`practice1_score/script.js` の `judge` 関数だけ
- ブランチ：`practice1`
- AI への頼み方のひな形：`prompts/practice1.md`

## 確かめ方

`index.html` をブラウザで開き、次の値を入れて［実行］を押します。

| 入れる値 | 表示されれば OK |
|---|---|
| 80 | 合格 |
| 60 | 合格（ちょうどの値） |
| 40 | 不合格 |

3つとも OK なら、add・commit・push に進みます。
