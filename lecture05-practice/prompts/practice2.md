# 問題2 AI への頼み方（ひな形）

コピーして、AI のチャット欄に1つずつ貼りつけて使います。
AI が実行したら、**かならず自分の目で結果を確かめてから**次へ進みます。

---

## ① 最新を受け取って、枝を作る

```
git pull で main ブランチを最新にしてください。
そのあと、practice2 という名前の新しいブランチを作って、そのブランチに切りかえてください。
```

✅ 自分で確かめる：ターミナルで `git branch` → `* practice2` になっていれば OK

---

## ② コードを書いてもらう（3つの要素で頼む）

```
【どこを】practice2_age/script.js の checkAge 関数の中だけを書きかえてください。ほかのファイルはさわらないでください。
【何を】if と else を使って、age が 18 以上なら show("成人です")、それ以外なら show("未成年です") と表示する処理を書いてください。
【確認】20 を入れたら「成人です」、18 を入れたら「成人です（ちょうどの値）」、15 を入れたら「未成年です」になるようにしてください。
```

✅ 自分で確かめる：`practice2_age/index.html` をブラウザで開いて、上の3つの値を試す

---

## ③ 記録する（add・commit）

```
practice2_age フォルダの変更を git add して、
「成人・未成年の判定を追加」というメッセージで git commit してください。
```

✅ 自分で確かめる：`git status` で「nothing to commit」、`git log --oneline` でメッセージが見えれば OK

---

## ④ GitHub に送る（push）

```
practice2 ブランチを GitHub に push してください。
```

✅ 自分で確かめる：GitHub のページで、ブランチの一覧に `practice2` が出ていれば OK
