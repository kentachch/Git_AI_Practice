# 問題1 AI への頼み方（ひな形）

コピーして、AI のチャット欄に1つずつ貼りつけて使います。
AI が実行したら、**かならず自分の目で結果を確かめてから**次へ進みます。

---

## ① 最新を受け取って、枝を作る

```
git pull で main ブランチを最新にしてください。
そのあと、practice1 という名前の新しいブランチを作って、そのブランチに切りかえてください。
```

✅ 自分で確かめる：ターミナルで `git branch` → `* practice1` になっていれば OK

---

## ② コードを書いてもらう（3つの要素で頼む）

```
【どこを】practice1_score/script.js の judge 関数の中だけを書きかえてください。ほかのファイルはさわらないでください。
【何を】if と else を使って、score が 60 以上なら show("合格")、それ以外なら show("不合格") と表示する処理を書いてください。
【確認】80 を入れたら「合格」、60 を入れたら「合格（ちょうどの値）」、40 を入れたら「不合格」になるようにしてください。
```

✅ 自分で確かめる：`practice1_score/index.html` をブラウザで開いて、上の3つの値を試す

---

## ③ 記録する（add・commit）

```
practice1_score フォルダの変更を git add して、
「合格・不合格の判定を追加」というメッセージで git commit してください。
```

✅ 自分で確かめる：`git status` で「nothing to commit」、`git log --oneline` でメッセージが見えれば OK

---

## ④ GitHub に送る（push）

```
practice1 ブランチを GitHub に push してください。
```

✅ 自分で確かめる：GitHub のページで、ブランチの一覧に `practice1` が出ていれば OK
